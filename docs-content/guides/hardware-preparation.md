## 为什么要提前准备硬件

PixelBeads 不是只在手机里使用的小程序。对门店来说，它是一套围绕“顾客到店体验”的经营系统：顾客选图、生成图纸、店员打印、发送到智能拼豆板、桌台计时、收银结算，这些流程需要线下硬件配合。

硬件准备到位以后，店员不需要临时找文件、临时连设备、临时解释图纸怎么拼。顾客看到的是一套完整体验：选图快、打印快、灯板引导清楚、结账有记录。

## 推荐准备哪些硬件

- 门店电脑：用于登录后台、连接 USB 打印设备、管理图纸和处理日常门店操作。
- 标签打印设备：用于门店服务相关服务标签。
- 彩色打印机：用于打印彩色图纸、顾客作品参考图、活动图纸和门店展示材料。
- 智能拼豆板：用于把图纸发送到灯板，让顾客按灯光提示完成拼豆。
- 稳定网络：后台、小程序、支付、团购核销和内容更新都需要网络稳定。

## 门店电脑

门店建议至少准备一台电脑，放在收银台或店员工作区。它主要用于连接打印机和处理后台操作。

建议配置：

- 能正常运行浏览器和打印机驱动。
- 支持 USB 接口，方便连接小票打印设备。
- 网络稳定，建议连接门店固定 Wi-Fi 或网线。
- 放在店员容易操作的位置，不要放在顾客频繁碰到的区域。

门店电脑的价值不是性能有多高，而是让打印、后台管理和收银流程有一个固定工作台。店员只要在这台电脑上完成打印和后台操作，就不容易出现文件找不到、设备连错、订单漏处理的问题。

## 标签打印设备

小票打印设备建议使用 USB 直连版本，不建议优先选择云打印。云打印依赖网络、平台和设备在线状态，门店高峰期一旦连接不稳定，会影响收银和出单节奏。

当前推荐：

- 型号：T271 USB 版。
- 参考价格：约 210 元。
- 连接方式：USB 连接门店电脑。
- 使用场景：收银小票、订单凭证、门店内部确认单。

采购时注意：

- 选择 USB 版，不要买成云打印版。
- 确认支持连接电脑使用。
- 到货后先安装驱动，再测试打印。
- 打印机建议固定放在收银台，不要频繁移动。

## 彩色打印机

彩色打印机主要用于图纸相关场景。拼豆门店经常需要给顾客打印参考图、图纸页、活动图、作品说明或店内展示材料，因此建议准备一台支持连接电脑的彩色打印机。

选择建议：

- 支持连接电脑打印。
- 彩色输出清晰，适合打印图纸和参考图。
- 后期耗材容易购买。
- 纸张尺寸满足门店常用图纸打印需求。

使用场景：

- 打印顾客选择的图纸。
- 打印 AI 生成或图片转换后的参考图。
- 打印门店活动图纸和主题图纸。
- 打印作品展示、套餐说明或活动物料。

注意事项：

- 彩色打印机不替代小票打印设备，两者用途不同。
- 图纸打印前要确认尺寸、颜色和页数。
- 店员应先用测试图纸打印一张，确认颜色和排版没问题。

## 智能拼豆板

智能拼豆板是门店体验里的核心硬件之一。它的作用不是简单展示图片，而是把图纸变成顾客可以跟着操作的灯光引导。

适合场景：

- 新手顾客不知道从哪里开始拼。
- 亲子顾客需要更直观的引导。
- 店员同时接待多桌，需要降低讲解压力。
- 门店希望把“智能灯板体验”做成特色卖点。

使用流程：

- 顾客选择或生成图纸。
- 店员确认图纸尺寸和难度。
- 将图纸发送到智能拼豆板。
- 顾客按照灯板提示完成拼豆。
- 完成后进入熨烫、打包或交付流程。

经营价值：

- 降低店员重复讲解成本。
- 提升新手顾客完成率。
- 让套餐更容易做出差异化。
- 帮助门店把桌台体验做得更标准。

## 推荐采购顺序

如果预算有限，可以按下面顺序准备：

- 第一优先级：门店电脑、标签打印设备。
- 第二优先级：彩色打印机。
- 第三优先级：智能拼豆板。

如果门店主打体验感和翻台效率，智能拼豆板建议尽早准备。它可以减少店员在每桌之间来回讲解的时间，让顾客自己跟着灯板推进。

## 开业前测试清单

- 门店电脑能正常登录后台。
- T271 USB 标签打印设备能从电脑正常打印。
- 彩色打印机能打印一张完整图纸。
- 智能拼豆板能成功连接并接收图纸。
- 店员知道打印机、灯板和后台分别在哪里操作。
- 高峰期前准备好打印纸、色带、墨水或其他耗材。

## 店家注意事项

- 不要把“云打印”当作首选方案，门店现场更推荐 USB 直连。
- 打印设备一定要提前测试，不要等顾客到店后再安装驱动。
- 彩色打印机要关注耗材成本，避免活动期临时缺墨。
- 智能拼豆板要和图纸尺寸、门店套餐设计一起考虑。
- 硬件放置位置要方便店员操作，也要避免顾客误碰。
