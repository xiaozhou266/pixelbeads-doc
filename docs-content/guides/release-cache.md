## 常见现象

- 文档目录没有更新。
- 小程序图片仍是旧图。
- 页面内容延迟展示。

## 排查步骤

- 确认后台内容已经保存并发布。
- 刷新页面或重新进入小程序。
- 等待 CDN 缓存刷新。
- 必要时联系技术人员检查发布记录。

## 店家建议

- 重要活动内容提前一天配置。
- 修改价格、套餐和活动后，自己用顾客视角检查一遍。
